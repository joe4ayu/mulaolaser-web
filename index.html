Order process

簡單四步，把想法刻出來。

  1. 討論需求提供用途、尺寸、數量、預算與想放上的文字或圖案。
  2. 整理圖稿協助確認線條、黑白稿、QR Code 或排版比例。
  3. 材質測試依木材或壓克力特性調整深淺與切割方式。
  4. 製作交件完成後可依需求包裝，適合送禮、活動與市集上架。
